# GTEL Maps Admin - Prototype UI/UX

Hệ thống Prototype UI/UX Final dành cho dự án **GTEL Maps Admin**, được xây dựng bằng HTML/CSS (Vanilla JS) phục vụ quá trình bàn giao cho đội ngũ Phát triển (Development Handoff).

## 🚀 Các Module chính
- **Dashboard Overview**: Thống kê và biểu đồ tổng quan.
- **IAM Center (RBAC)**: Quản trị ma trận quyền và phân nhóm bảo mật.
- **Project Management**: Khởi tạo và quản lý dự án.
- **API Key Management**: Quản trị mã truy cập và Whitelist.
- **Audit Logs**: Nhật ký truy vết hành động.

## 🔗 Hướng dẫn xem nhanh
1. Mở file `index.html` để truy cập vào Launchpad điều hướng.
2. Tất cả mã nguồn logic JS và CSS chung nằm trong `shared.js` và `shared.css`.

## 🛠 Deploy
Dự án sẵn sàng để deploy lên **Vercel** hoặc **Netlify** bằng cách kết nối trực tiếp với Repository này.
