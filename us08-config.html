Ngôn ngữ hệ thống (system.localization.defaultLanguage)

Thiết lập ngôn ngữ mặc định và danh sách ngôn ngữ hỗ trợ cho giao diện và API phản hồi.

Default: vi-VN

Theme mặc định (system.appearance.defaultTheme)

Thiết lập giao diện Sáng/Tối cho toàn bộ hệ thống, ảnh hưởng đến cách hiển thị Basemap.

Chế độ bảo trì hệ thống

Tính năng quản trị: Tạm dừng truy cập Portal khi nâng cấp hạ tầng.

Bản đồ nền mặc định (system.map.defaultBasemap)

Mã bản đồ nền khởi tạo cho Map Viewer toàn bộ hệ thống.

Phạm vi hiển thị mặc định (system.map.defaultViewport.bbox)

Xác định vùng nhìn bản đồ mặc định khi khởi tạo (Bounding Box).

Format: [[minLon, minLat], [maxLon, maxLat]]

Chính sách xác thực 2 lớp (system.auth.twoFactorPolicy)

Quy định phương thức bảo mật khi đăng nhập Admin Portal.

Phương thức xác thực 2 lớp ổn định

allowedSecondFactors: ["email_otp"]
